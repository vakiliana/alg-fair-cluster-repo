# alg-fair-cluster-repo

A curated repository of papers, notes, and resources on the **algorithmic foundations of fair clustering**.

## Overview

This repository collects work at the intersection of:

- Clustering algorithms
- Fairness in machine learning
- Theoretical computer science
- Optimization and approximation methods

The goal is to make it easier to discover and organize research on how clustering objectives and constraints can be designed to satisfy fairness criteria.

## Topics Covered

- Fairness notions for clustering (e.g., balance, representation, group fairness)
- Constrained and fair variants of classic clustering problems
- Approximation and complexity results
- Trade-offs between utility and fairness
- Practical and empirical studies of fairness-aware clustering
- Related surveys and benchmark datasets (when available)

## Repository Structure

> Update these sections as the repository grows.

- `papers/` – paper list, bibliographic data, and links
- `notes/` – reading notes and summaries
- `code/` – reference implementations (if included)
- `data/` – datasets or links to datasets (if included)

## How to Use This Repository

1. Browse the paper collection by topic or method.
2. Use notes for quick summaries of key ideas and results.
3. Follow links to official papers, code, and supplementary material.
